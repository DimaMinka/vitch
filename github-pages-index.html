System Engineering Specs

Configured for High Throughput Outputs

Instant Lossless Stream Copy

Uses FFmpeg’s high-velocity concate demux logic to instantly copy audio and video packets without a single byte of decoding, reducing render time to zero while retaining 100% of original fidelity.

Tetrahedral LUT Interpolations

Processes on-the-fly cinematic conversions to Rec.709 or custom film spaces. Fully supports 3D LUT look-up filters without quality loss or highlight banding artefacts.

Looped Backtrack Multi-Pads

Mount custom high fidelity stereo scores (`.wav` or `.flac`) that sync perfectly. Automatically loops small tracks continuously and closes them instantly the moment video renders finish.

Local macOS execution instructions

After configuring your script on Vitch, write it directly into your movie directory using the following terminal procedure to initiate high-speed rendering:

# 1. Open Terminal.app and switch directory to your Movie folder:
cd ~/Movies/RawProjects/SummerHolidays/
# 2. Make downloaded file 'assemble.sh' an executable script:
chmod +x ~/Downloads/assemble.sh && mv ~/Downloads/assemble.sh .
# 3. Fire the FFmpeg Vitch pipeline compiler:
./assemble.sh

Note: Vitch targets system package paths on Darwin platforms and automatically builds homebrew dependencies if warning indicators trigger during startup.
